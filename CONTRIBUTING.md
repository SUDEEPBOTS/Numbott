# 🤝 Contributing Guidelines

First off, thank you for considering contributing to **Numbott Telethon**! It's contributions like yours that make the open-source community an amazing place to learn, inspire, and create.

---

## 📜 Code of Conduct

- Be respectful and considerate of other contributors.
- Focus on constructive criticism and helpful feedback.
- Keep security in mind: **NEVER commit bot tokens, API keys, or database files!**

---

## 🛠️ How to Contribute

### 1. Fork & Clone
1. Fork the Project Repository.
2. Clone your fork locally:
   ```bash
   git clone https://github.com/YOUR_USERNAME/Numbott.git
   cd Numbott
   ```

### 2. Create a Feature Branch
```bash
git checkout -b feature/AmazingFeature
```

### 3. Commit Your Changes
Keep commit messages concise and descriptive:
```bash
git commit -m "Add some AmazingFeature"
```

### 4. Push to Branch & Open Pull Request
```bash
git push origin feature/AmazingFeature
```
Then create a **Pull Request (PR)** against the `main` branch.

---

## 🐛 Reporting Bugs

If you find a bug or issue:
1. Open an issue on GitHub.
2. Clearly describe the problem, including steps to reproduce.
3. Attach logs if available (be sure to mask sensitive keys!).
